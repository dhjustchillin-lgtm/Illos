# About **`Adamas Edition`**

<!-- If you want to re-record or change these gifs, here are some notes that I used: https://files.catbox.moe/05001g.md -->

**`Adamas Edition`** is a GBA ROM hack set in the Greece-based region of Illos. **`Adamas Edition`** is currently in development, and is **not fully released yet.**

# Region

**`Adamas Edition`** is set in Illos, a region that believes that Pokemon are nothing more than animals. The beasts to pull the plows. The pets to amuse the children. The food put on the table. The pests that eat the crop roots.
